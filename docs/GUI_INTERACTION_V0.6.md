# V0.6 GUI 与交互设计

## 1. 一级导航

```text
运行驾驶舱
模板库
新建任务
实时监控
任务中心
结果分析
系统诊断
```

“实时监控”用于运行期间，“任务中心”用于历史管理，两者职责分离。

## 2. 运行驾驶舱

第一屏只呈现需要即时决策的信息：

- 服务 / PyMotorCAD / SSE连接状态；
- CPU / Memory / Disk；
- Worker利用率；
- 系统健康与告警；
- 当前活动任务；
- 最近任务。

## 3. 新建任务反馈

表单底部实时显示：

```text
Case数量
工程参数修改数量
专家参数数量
Solver control数量
```

用户修改模板默认参数后输入框高亮，可直观看出当前设计相对于母版的变化。

## 4. 实时监控页

页面被设计成仿真“控制室”：

- 顶部：任务选择、实时连接状态；
- KPI：进度、elapsed、ETA、吞吐、成功/无效；
- 左：阶段 Pipeline；
- 右：Worker与Motor-CAD PID、CPU、内存、心跳；
- 下左：Case矩阵；
- 下右：事件流。

## 5. 结果分析页

批量任务不再只显示单Case。用户可以：

1. 选择Task；
2. 选择任一数值设计参数为X；
3. 选择任一标量输出为Y；
4. 在散点/折线图之间切换；
5. 点击异常点定位Case；
6. 查看各参数与目标输出的Pearson相关系数；
7. 按质量状态筛选数据表。

## 6. 交互快捷能力

- `Ctrl/Command + K` 打开命令面板；
- `Esc` 关闭；
- Theme按钮切换深色/浅色；
- SSE断线自动重连；
- Warning/Error即时toast；
- 系统异常在驾驶舱形成固定告警，不只依赖弹窗。
