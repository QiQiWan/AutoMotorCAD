# MotorCAD Studio V0.6 实施说明

## 1. 版本目标

V0.6 将重点从“PyMotorCAD 全集成能力”转向“工程仿真运行的人机交互质量”。后台求解架构沿用 V0.5，新增独立 Monitoring Plane，使 GUI 可以在 Motor-CAD 长时间阻塞求解期间持续反馈平台状态。

核心目标：

```text
任务可看见
进程可看见
资源可看见
异常可看见
结果关系可看见
用户下一步操作可明确判断
```

## 2. Monitoring Plane

新增 `motorcad_studio/monitoring.py`，只读访问 SQLite、psutil 与运行目录，不持有 Motor-CAD RPC 对象。

这样即使 Worker 正阻塞在 `do_magnetic_calculation()`、`do_steady_state_analysis()` 等调用中，FastAPI 仍可读取：

- Task / Case 状态；
- 当前 Stage；
- Worker PID；
- Worker 进程树 CPU / 内存；
- Worker 子进程中的 Motor-CAD PID；
- heartbeat 新鲜度；
- 主机 CPU / 内存 / 结果磁盘；
- Motor-CAD 系统进程；
- Worker 容量与利用率；
- 系统告警。

## 3. 实时事件通道

新增 Server-Sent Events：

```text
GET /api/system/stream
GET /api/tasks/{task_id}/stream
```

Task stream 提供两种事件：

```text
task_event     平台已有 Task / Case / Worker / Stage 事件
task_snapshot  Task 进度、ETA、吞吐、活动Case、阶段汇总
```

浏览器断线后 `EventSource` 自动重连。Task event 使用事件 ID 游标，避免每次刷新读取整个事件列表。

固定 3 秒 REST 轮询仍仅保留在传统“任务中心”作为兼容路径；新的“实时监控”页面采用 SSE。

## 4. ETA 与吞吐

Task monitor 根据当前实际运行时间和整体 progress 给出动态 ETA：

```text
ETA = elapsed * (1-progress) / progress
```

同时输出：

```text
throughput_cases_per_min
```

这些值属于运行估计，不作为求解器保证时间。

## 5. 运行驾驶舱

首页新增：

- CPU 利用率；
- 内存占用；
- 结果磁盘；
- Worker 容量 / Busy / Available；
- Motor-CAD进程数量；
- 系统健康分；
- 活动 Worker；
- 自动告警。

告警规则目前覆盖：

- 磁盘 > 80% / 90%；
- 内存 > 82% / 92%；
- Worker PID丢失或复用；
- Worker heartbeat 超时；
- 未启用实例复用且无活动 Worker 时检测到 Motor-CAD 残留进程。

## 6. 实时任务监控

新增“实时监控”页，包含：

1. 总进度、elapsed、ETA、吞吐；
2. 活动 Case、成功、无效、未验证计数；
3. Stage pipeline；
4. Worker进程树资源表；
5. Case状态矩阵；
6. 统一事件控制台；
7. Warning / Error筛选；
8. 重要事件 toast。

Case矩阵颜色用于快速定位：

```text
灰色    Pending
蓝色    Running
绿色    Valid
橙色    Warning
红色    Invalid / Failed
紫色    Unverified
```

## 7. 批量结果分析

新增：

```text
GET /api/tasks/{task_id}/analytics
```

后端将 Case 的数值参数与 scalar results 扁平化为统一数据表，并生成基础统计量。

GUI 提供：

- 参数—结果散点图；
- 参数—结果折线图；
- 点击数据点识别 Case；
- 质量状态着色；
- Pearson 快速敏感性排序；
- 结果均值 / min / max / median；
- Case结果数据表；
- 质量过滤；
- Case关键词过滤。

Pearson 相关仅作为筛查指标，不替代 Sobol、Morris 或正式全局敏感性分析。

## 8. 人机交互改进

新增：

- 深色 / 浅色主题；
- Ctrl/Command + K 命令面板；
- 任务配置实时摘要；
- 被修改的工程参数高亮；
- SSE连接状态徽标；
- Warning / Error / Complete toast；
- 响应式监控布局；
- 动态资源进度条；
- 实时系统健康分。

## 9. Motor-CAD 监控边界

PyMotorCAD 的 `get_messages()` 可以获取消息历史，`clear_message_log()` 可以清理日志；Graph API 可以在求解完成后提取曲线。但常规 `do_magnetic_calculation()` 等 RPC 调用本身是同步阻塞调用。

V0.6 因此不伪造“Motor-CAD内部精确求解百分比”。当前实时反馈分为：

```text
平台阶段进度
Worker / Motor-CAD进程健康度
系统资源变化
Case heartbeat
阶段结束后的Motor-CAD消息解析
```

若后续目标版本验证了安全的并发消息RPC或内部回调机制，可进一步将 Motor-CAD 子阶段消息流实时映射到 SSE。
