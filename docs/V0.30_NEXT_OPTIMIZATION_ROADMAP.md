# V0.30 之后的深层优化路线

## P0 — V0.31 Browser E2E + Formal Migration

V0.30 已收敛工程语义，下一风险是“代码存在”与“真实点击路径可用”之间仍有差距。

建立 Playwright/Chromium 端到端链：

项目 → 从模板创建电机 → 修改设计 → 设置工况 → 选择分析 → 开始计算 → 实时进度 → 结果 → 浏览器刷新 → Back/Forward → 再次修改。

故障路径覆盖：重复点击、慢 API、页面离开时未完成请求、Task 404、Dialog 关闭、重复提交、计算失败后的定位修复。

数据库同步从 `CREATE TABLE IF NOT EXISTS + ensure_column()` 迁移到正式版本化 migration：备份 → schema lock → ordered migration → integrity_check → READY。

## P0 — Windows Motor-CAD Contract Campaign

在真实 Motor-CAD 2026R1 工作站运行：

- 20/100/500 Case 持续复用
- Worker recycle
- RPC timeout / BrokenPipe
- Motor-CAD crash
- License unavailable / restored
- Studio restart
- 模板版本变化
- 内存阈值回收

用实际数据确定 Persistent Worker 的默认 recycle jobs/RSS，而不是继续依赖经验值。

## P1 — V0.32 Native Geometry + Structured Winding

快速 SVG 继续承担即时交互；增加真实 Motor-CAD Region/Entity/Coil 数据视图。

目标：

错误 → 真实 Region/Coil 高亮 → 关联参数 → 上一可行版本 → 修改 → Native Validation。

这会进一步缩小与 Motor-CAD Geometry/Winding Editor 的交互差距。

## P1 — V0.33 Native FEA Mesh Renderer

在 V0.23 原生 FEA Evidence 基础上升级：

- Nodes / Elements
- B / Pt / J 等字段
- mesh / contour / vector
- step playback
- 统一色标
- 原始证据与可视化帧一致性检查

禁止用 Studio 示意场冒充 Motor-CAD 原生场。

## P1 — V0.34 Engineering Decision Workspace

从“查看一条结果”升级为“比较多个设计版本”：

- 关键性能并排
- 质量状态
- 模型可行性
- 与基准版本变化
- 设为候选/基准
- 创建下一设计版本
- 加入 DOE/优化

## P2 — V0.35 Output Calibration Assets

按 `Motor-CAD Version × Template Family × Analysis` 建立结果映射资产：

canonical output → automation candidates → graph fallback → derived fallback → unit → evidence。

重点降低“求解成功但常用输出缺失”的 Quality Warning。

## P2 — V0.36 AI-ready Data Provenance

Dataset 进一步冻结：

- Run Configuration hash
- Validation Evidence
- Motor-CAD/PyMotorCAD version
- MOT/template hash
- material DB/BH/loss-curve hash
- output calibration version
- Native FEA evidence version

确保后续代理模型、优化模型和预训练数据具备工程可复现性。
