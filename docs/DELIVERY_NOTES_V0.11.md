# V0.11 Delivery Notes

本次交付以用户实际截图审计为入口，重点消除“开发者知道怎么用，但普通工程师不知道怎么用”的问题。

## 已处理的截图问题

- Project删除已加入。
- 实时通道持续重连根因已修复，并增加Polling fallback。
- AFPM/RFPM示意图改为参数驱动工程风格。
- Engineering Parameter Inspector已改名、重排并加使用说明。
- Expert与Solver高级选项增加中文说明并默认折叠。
- 常用材料改为选择器。
- 自动化任务、结果分析、数据工厂、日志、运行检查均有Help入口。
- Result Viewer已作为一级模块加入。
- Data Factory采用中文优先并提供中英文切换。
- 诊断包可在线下载中央/滚动/Case日志。
- 深度运行检查已进程隔离并修复许可证语义。

## 安全边界

项目删除默认只删除工程对象树，不删除历史计算和数据工厂产物；如果未来开放“彻底删除”，应继续要求二次确认并展示将删除的Task/Case/Dataset数量。
