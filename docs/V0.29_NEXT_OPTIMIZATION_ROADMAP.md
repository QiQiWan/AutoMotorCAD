# V0.29 后续深层优化路线

## P0：真实工程流程可靠性

### 1. Browser E2E

用 Playwright 实际执行：

```text
Project → Model → Revision → Simulation
→ Scenario → Outputs → Submit → Monitor → Result
→ Refresh → Back → Forward
```

并验证 deep link、路由取消、重复点击、表单脏状态、页内 Dialog 和失败修复入口。当前运行环境的 Chromium 策略阻止 localhost 导航，因此 V0.29 已完成代码契约测试，但浏览器 E2E 仍需在可访问本地 Studio 的 CI/Windows 环境执行。

### 2. Windows Motor-CAD Contract

至少覆盖 20/100/500 Case：

- persistent session reuse；
- RPC timeout；
- Motor-CAD crash；
- worker kill；
- licence unavailable/recovery；
- cancellation；
- FEA export schema variation；
- long-run RSS growth；
- installation switch；
- registered template change。

## P0：正式数据库 Migration

替换 `CREATE TABLE IF NOT EXISTS + ensure_column + query-time recovery`：

```text
startup lock
→ backup
→ detect schema
→ ordered migration
→ integrity_check
→ foreign_key_check
→ service ready
```

Migration 失败必须在运行环境页显式阻断。

## P1：Motor-CAD Native Model Workspace

### Native Geometry

通过 PyMotorCAD Region/Entity API 建立真实几何 Viewer：

```text
Region Tree ↔ Native Geometry ↔ Parameter/Issue
```

保留快速示意用于毫秒级随动；Native Geometry 用于权威几何证据。

### Structured Winding

使用实际 coil go/return slot、position、turns 构建真实绕组图。把 Slot Fill、Winding Area、Conductors/Slot 与相关槽/coil 同屏显示。

## P1：FEA 与结果决策

- 原生 mesh / element / node 数据渲染；
- B、A/Pt、J 等场切换；
- step playback；
- 统一色标；
- Design Revision 横向比较；
- Pareto / constraint status；
- “设为基准 / 创建下一 Revision / 加入 DOE / 加入 Dataset”。

## P1：输出映射校准

对目标 Motor-CAD 版本建立 Output Calibration Asset：

```text
canonical output id
→ automation candidates
→ graph/derived fallback
→ units
→ template/version applicability
→ validation evidence
```

减少“求解成功、质量 WARNING、某些常用输出缺失”。

## P2：AI-ready Engineering Data

数据集至少冻结：

- Run Configuration hash；
- Design/Scenario revision；
- Motor-CAD/PyMotorCAD version；
- model/template hash；
- automation mapping hash；
- material database/BH/loss curve hash；
- Validation Evidence；
- Native FEA manifest/hash；
- quality flags；
- failure root cause。

然后再进入 feasibility-aware DOE、active learning、surrogate uncertainty 和 Pareto candidate 回写。
