# MotorCAD Studio — V0.22 之后的深层优化路线

## 总体判断

V0.22 已经解决“流程入口太多、参数缺少联动、提交噪声高、求解过程不可见、输出重复勾选”等直接问题。下一阶段的差距集中在三层：Motor-CAD 原生模型可视化证据、页面生命周期/前端核心、Motor-CAD 实例运行时管理。

## V0.23 — Native FEA Evidence & Motor-CAD Runtime Supervisor（P0）

### 1. 原生 FEA 数据回放

在 EMag Case 完成后使用 PyMotorCAD `save_fea_data()` 导出经过工作站验证的 step range，并形成：

```text
native_fea_manifest.json
frames/
  step_000.json.zst
  step_001.json.zst
  ...
```

每帧应至少保存：

```text
X, Y, RegionCode, Bx/By or B, VectorPotential
rotor_position
step_index
source_mot_hash
Motor-CAD version
```

浏览器采用 Canvas/WebGL 绘制真实 shading、mesh、vectors、equipotential 等图层，并与 TorqueVW / B Gap / Case stage 同步。

### 2. 实时 FEA 流可行性验证

建立 Windows contract experiment：

```text
Solver RPC Client A
  └─ do_magnetic_calculation()

Read-only RPC Client B
  └─ 查询求解状态 / 可用 FEA step
```

只有证明同一实例并发只读安全后才启用“真实实时 FEA”。如果并发 RPC 不安全，产品定义为：求解期间显示真实进度 + 模型运动，求解后立即播放真实 FEA 场帧。

### 3. Motor-CAD Session Supervisor

每个实例显式建模：

```text
Session ID
PID
RPC Port/URL
Motor-CAD Version
Owner Task/Case
State
Memory RSS
Jobs Completed
Last Heartbeat
Last Native Message
```

实现：

```text
allocate → prepare → solve → release
                    ↓
      jobs/RSS/RPC threshold
                    ↓
                 recycle
```

利用 PyMotorCAD 的 `keep_instance_open` / `reuse_parallel_instances` 形成受控热池，默认仍保持正确性优先。

## V0.24 — Motor Model Workbench（P0/P1）

把当前参数页升级为三栏工程工作台：

```text
参数/Region树 | Native Geometry / Fast Schematic | Constraints / Evidence
```

主要能力：

- Geometry Region / Entity 选择与参数反向定位；
- Winding Pattern 可视化；
- 槽、齿、轭、磁钢、气隙尺寸标注；
- 参数 dependency graph；
- Native Geometry Snapshot；
- 错误直接锚定参数；
- 与上一可行 Revision 差异对比；
- 一键恢复局部可行值。

## V0.25 — Route-first Frontend Core（P0）

V0.22 仍保留 `showTab + global state + setTimeout` 的历史结构。应把 Router 从 URL 包装器升级成页面生命周期拥有者：

```text
Router
→ Context Resolver
→ Page Controller
→ load(AbortSignal)
→ render
→ bind
→ dispose
```

并拆分 ES Modules：

```text
/core/router
/core/store
/core/api
/core/i18n
/pages/model
/pages/calculation
/pages/solve
/pages/results
/components/model-viewer
/components/validation
```

所有页面切换自动 cancel 旧请求，从根源消除异步页面覆盖。

## V0.26 — Result / Graph Workspace（P1）

形成接近 Motor-CAD Graph Viewer、同时保留 Studio 版本比较优势的结果中心：

```text
左：结果树
中：曲线/Map/FEA Viewer
右：RunConfig/Revision/Quality Evidence
```

默认提供：

- Torque vs Angle；
- Airgap B vs Mechanical Angle；
- Efficiency / Loss；
- Temperature；
- Harmonics；
- 多 Revision overlay；
- 可行/不可行 Revision 对比。

## V0.27 — Reliability Engineering（P1）

必须补齐 Windows + Browser 真实 E2E：

```text
Project
→ Template
→ Design Revision
→ Scenario
→ Calculation
→ Native Gate
→ Submit
→ Live Solve
→ Result Playback
→ Refresh / Back / Forward
```

故障注入：

```text
Motor-CAD crash
RPC timeout
license unavailable
BrokenPipe
DB locked
worker kill
orphan process
stale route
output mapping missing
FEA export unavailable
```

数据库迁移改为启动期版本化 migration，不再在查询路径中补表。

## V0.28 — AI-ready Design Space（P2）

当 Native Evidence 和运行时稳定后，再进入 AI 数据层：

- Dataset schema 固化 Design/Scenario/Solver/Output/RunConfig lineage；
- 记录 Motor-CAD/PyMotorCAD/version mapping checksum；
- 材料曲线 checksum；
- Native validation evidence；
- FEA field feature extraction；
- 基于可行域的 DOE；
- surrogate / active learning；
- 多目标优化结果回写 Revision Candidate。

## 推荐实施顺序

```text
V0.23  Native FEA + Session Supervisor
  ↓
V0.24  Motor Model Workbench
  ↓
V0.25  Route-first Frontend Core
  ↓
V0.26  Graph / Decision Workspace
  ↓
V0.27  Windows E2E + Fault Injection
  ↓
V0.28  AI-ready Design Space
```

其中 V0.23 应作为下一轮首要工作。当前软件和 Motor-CAD 体验差距最明显的部分已经从“有没有功能”转移到“模型和求解过程是否持续、可信、可视”。
