# V0.26 之后的深层优化路线

## 结论

V0.26 解决了正式 Case 内部“校验和求解分离”的主要运行时风险，并建立了可复用 Motor-CAD Worker owner。下一阶段不应立即增加更多业务页面。优先级应转向持久运行可靠性、版本化数据库迁移、真实几何/绕组证据和浏览器级 E2E。

## P0：V0.27 Runtime Contract & Scheduler

### 1. License-aware Worker Scheduler

当前 TaskManager 先获取 license semaphore，再等待 solver/worker capacity。在 license 数量和 Worker 数量不一致时，有机会出现“持有 license 但等待 Worker”。

目标：

```text
Scheduler Request
  ├─ Analysis capability
  ├─ License requirement
  ├─ Worker capability
  ├─ Motor-CAD version
  └─ memory budget
          ↓
atomic resource lease
          ↓
Worker + License + Session
```

统一 lease 后再开始 Case。

### 2. Windows Motor-CAD Contract Test

至少验证：

- 100 Case sequential reuse；
- 2~N Worker parallel；
- cancel during RPC；
- forced Worker kill；
- Motor-CAD crash；
- license unavailable / regained；
- registered template change；
- manual installation switch；
- RSS recycle；
- repeated set_free/reuse；
- Studio shutdown graceful cleanup。

输出 machine-readable contract report，正式参与 Runtime Readiness。

### 3. Worker capability handshake

持久 Worker 启动后主动报告：

- Python version；
- PyMotorCAD version；
- configured Motor-CAD executable；
- Motor-CAD target version；
- architecture；
- install ID；
- supported analysis contexts。

不匹配 Worker 不能接收 Case。

## P0：正式数据库 Migration

当前仍使用：

`CREATE TABLE IF NOT EXISTS + _ensure_column + query-time no-such-table retry`。

正式目标：

```text
startup
→ exclusive migration lock
→ backup
→ read schema version
→ ordered migration scripts
→ integrity_check
→ foreign_key_check
→ service READY
```

失败时阻断工程服务，并在运行环境页提供备份位置/失败 migration/恢复动作。

## P1：Native Geometry + Structured Winding Evidence

V0.24 Workbench 的快速几何仍属于 Studio schematic。

下一层：

```text
Fast Schematic
Motor-CAD Native Geometry
Motor-CAD Winding Pattern
```

Native Geometry 使用真实 Region / Entity / Line / Arc / Coordinate 数据；Winding 使用 phase/path/coil、go slot、return slot、turns。

错误可以直接映射到真实 Region / Coil。

## P1：Native FEA Mesh Renderer

V0.23/0.24 已保存 FEA raw evidence。下一阶段应：

- 建立 Nodes / Elements / Regions 标准中间格式；
- Canvas/WebGL mesh renderer；
- B / Pt / J / Loss / Temperature field；
- shared color scale；
- mesh / contour / vector layer；
- step timeline；
- compare two Cases。

求解中实时读取仅在 Windows contract test 证明并发只读 RPC 安全后启用。

## P1：Engineering Decision Workspace

结果页从 Result Viewer 升级为设计决策页：

```text
              Rev.5    Rev.6    Rev.7
Torque        ...      ...      ...
Efficiency    ...      ...      ...
Loss          ...      ...      ...
Temperature   ...      ...      ...
Geometry      PASS     PASS     FAIL
Winding       PASS     PASS     PASS
Evidence      L4       L4       L2
```

提供“设为基准 / 创建下一 Revision / 加入 DOE / 加入 Dataset”。

## P1：浏览器 E2E + Fault Injection

Playwright 自动完成：

```text
Project
→ Template
→ Design
→ Revision
→ Scenario
→ Solver / Output
→ Submit
→ Validate-and-Run
→ Monitor
→ Result
→ Refresh
→ Back / Forward
```

故障注入：

- stale route；
- network retry；
- Task POST response loss；
- RPC timeout；
- Worker crash；
- DB lock；
- disk full；
- malformed Motor-CAD message；
- FEA export failure。

## P2：AI-ready Data Provenance

Dataset Version 最终还需冻结：

- Run Configuration hash；
- Validation Evidence hash；
- Worker generation；
- Motor-CAD/PyMotorCAD version；
- MOT / template hash；
- material database checksum；
- Automation Mapping version；
- FEA evidence hash；
- result extraction catalog hash。

这样后续 surrogate model / optimizer 才能区分软件版本和求解器状态造成的 domain shift。
