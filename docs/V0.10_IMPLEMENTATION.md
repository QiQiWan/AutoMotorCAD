# MotorCAD Studio V0.10 Implementation

V0.10 的定位是 **Engineering UX & Observability Edition**。没有引入 AI，也没有把版本号推进到 V1.0，因为真实 Motor-CAD 数据工厂的大规模实机验收仍未完成。

## 核心增量

### Engineering Workspace

- Project Explorer；
- Design browser；
- immutable Design Revision；
- RFPM/AFPM schematic；
- revision snapshot/clone；
- Design Revision -> Task Builder。

### Template UX

- topology schematic；
- maturity visualization；
- template comparison。

### Parameter UX

- search；
- changed only；
- changed highlighting；
- reset changed values。

### Runtime UX

- stage performance mean/median/P95/max；
- waiting reason；
- existing SSE/process-tree/license/case-matrix integration。

### Observability

- central rotating JSONL；
- text log；
- audit log；
- per-Case solver log；
- Request ID；
- Task/Case/Stage traceability；
- monitoring alert transitions；
- aggregated diagnostics；
- live log SSE；
- diagnostic ZIP；
- offline analyzer。

## Runtime correlation

推荐问题分析顺序：

```text
Request ID
 -> Task ID
 -> Case ID
 -> Stage
 -> Worker PID
 -> Motor-CAD PID
 -> Case Artifact
 -> Dataset lineage
```

这一条链把用户操作、任务调度、Solver和Data Factory连接起来。

## 设计原则

1. 高频 progress 默认 DEBUG，不污染生产 INFO 日志；
2. 系统资源告警只记录状态变化；
3. Solver child 不并发写中央文件，通过现有 IPC queue 回传；
4. Case 目录保留独立 solver_runtime.jsonl；
5. 敏感键递归脱敏；
6. 日志序号跨服务重启继续递增；
7. Diagnostic Bundle 是真实工作站问题反馈的标准工件。
