# MotorCAD Studio V0.40：模型优先工程工作台

## 发布结论

V0.40 已完成本轮产品实现范围：模型无需从模板入口创建；新项目可直接获得默认 BPM 模型；机型、模板、MOT 与 Revision 均可作为模型来源；参数自由度扩展到版本化工程参数与目标 Motor-CAD Automation Parameter Names；仿真入口升级为五模块、17 配方的分析工作台；结果视图优先显示空间场、曲线、热拓扑和工程指标。

“产品实现完成”与“目标工作站资格通过”分开计量。前者由代码、数据合同、无求解器服务验收和静态检查验证。后者必须在 Windows + Motor-CAD 2026R1 + 有效许可证环境运行，当前 Linux 交付环境无法生成该证据。

## 2. 参数自由度

参数目录由两层合并：

1. `parameter_registry.yaml` 与 `solver_versions/2026R1/parameter_mapping.yaml` 提供有单位、类型、上下限和候选 Automation Name 的工程参数；
2. 用户从 Motor-CAD “Automation Parameter Names” 导入的版本/机型/上下文参数提供长尾自由度。

目录支持 EMag、Therm、Lab、Mechanical 上下文筛选，区分读写方向和是否经过人工复核。保存操作生成新的不可变 Revision；Task 提交时把 Revision 级 Automation 参数与本次任务覆盖合并。

## 3. 分析工作台

| 模块 | 配方 |
|---|---|
| EMag | 单工作点、饱和图、转矩包络、多位置电磁力、空间/时间力谐波 |
| Therm | 稳态热、瞬态热 |
| Coupled | 电磁后稳态热、Motor-CAD 原生电磁-热耦合 |
| Lab | 磁性性能图、工作点、热模型、占空循环、发电工况、测试性能 |
| Mechanical | 机械计算、重量计算 |

Analysis Definition 将 Design Revision、配方、工况矩阵、求解设置和输出请求作为独立版本化对象保存。同一电机模型可以并列维护多种计算。进入高级计算设置时自动恢复模型版本、分析类型、首个工况、输出和任务名称。

分析可用性同时受前端机型目录与后端 Design Revision 能力快照约束。即使用户在高级设置中手动切换到当前机型未声明的配方，提交前也会以 `ANALYSIS_UNAVAILABLE_FOR_MOTOR_TYPE` 阻断，避免借用兼容模板的能力造成误放行。

## 4. 工程结果优先

结果页面的默认阅读顺序为：

1. 质量状态与关键工程指标；
2. 标量卡片和时序/性能曲线；
3. Motor-CAD 原生 FEA 场视图；
4. 热网络拓扑与温度/热流证据；
5. 原生成果文件与诊断证据。

FEA 数据合同支持 B、Bx、By、Pt、电流密度 J、涡流密度 Jeddy、区域、Step、元素编号与节点编号。前端提供场变量、区域、色标、步进回放和最近原生点探测。缺少连续网格连接时使用原生点场着色，并明确关闭网格/填充等值线能力。

## 5. 实时求解合同

`/api/cases/{case_id}/fea-stream` 使用 Server-Sent Events 发布求解阶段、进度、原生帧数量和原生画面地址。Motor-CAD 的同步计算调用期间显示真实阶段与进度；`save_fea_data()` 或原生画面可用后立即更新视图。系统不使用插值动画冒充求解器场结果。

每个可用原生画面保存 PNG、大小、SHA-256、Motor-CAD Screen 名称和捕获时间。原生 FEA 数据保存 CSV、Step 范围、输出字段、来源 MOT 哈希、归一化清单和逐帧 JSON。JSON 面向 API/开发者诊断，工程视图默认消费这些合同并呈现可视化。

## 6. 数据与迁移

Schema 18 新增：

- Design 的 `motor_type_id/source_kind/source_reference/geometry_mode/source_mot_path/capability_snapshot_json`；
- Design Revision 的 `automation_parameters_json/capability_snapshot_json/source_snapshot_json/mot_artifact_path`；
- `analysis_definitions` 与 `analysis_definition_revisions`。

旧项目和模板创建流程继续可读写。旧 Design 没有新字段时使用兼容默认值，不会改写历史 Revision。
