# Engineer Workflow

## Design

Create a Golden Motor Starter (SPM, IPM or AFPM), edit guided engineering parameters, review geometry/material/winding state, and save immutable Design Revisions.

## Validate

Use the Standard Validation Package to materialize the recommended analysis set. Studio and native prechecks remain authoritative. Completed ResultBundles are summarized into the Engineering Scorecard.

## Decide

Use baseline comparison, 1D/2D parameter study, Pareto/convergence/sensitivity views and Candidate Inspector. Candidate promotion reuses the validation/requirement gate and creates a new immutable Design Revision.

## Guided-mode rule

The default engineer workflow does not require Python, Automation API names, JSON, database schema knowledge or worker/runtime concepts. These remain available only through advanced diagnostics/developer surfaces.
