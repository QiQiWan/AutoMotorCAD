## Qualification rule

A fixed control passes registration only when it has a stable HMI control identity and a proven click owner (`direct`, inline `onclick`, declared delegated family, or a declared deferred page owner). The actual-click browser sweep then exercises every fixed control that is enabled in the current state and records workflow-gated controls separately.

Dynamic controls are not frozen into this table because their instances depend on project/task/result state. The runtime registry observes mutations, assigns semantic action-family identities, and includes every currently rendered dynamic button in `qualify()` and exported JSON evidence.
