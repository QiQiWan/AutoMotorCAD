# MotorCAD Studio V0.35：集成工程分析与完成度评估

## 1. 本轮目标

V0.35 沿用 V0.31 已建立的 `径向 / 轴向 / 绕组 / 槽内 / 材料 / 原生证据 / 版本对比` 设计视图，把后续四个增量整合为可验收闭环：

| 版本增量 | 核心目标 | V0.35 交付 |
|---|---|---|
| V0.32 | 绕组定义结构化 | 保存原生绕组文本后解析线圈、相别、进/回槽、匝数与支路；生成带 SHA-256 的 `winding_definition.json` |
| V0.33 | 热结果拓扑化 | 后端统一原生热网络与温度摘要数据合同，前端显式区分 `NATIVE_NETWORK` 与 `SUMMARY_ONLY` |
| V0.34 | FEA 证据工作台 | 多步回放、字段/区域选择、全范围/分位/手动色标、最近原生点探测、原始 CSV 下载 |
| V0.35 | 跨方案决策分析 | 同时比较设计、工况和求解设置，增加目标方向、非支配解、改善/退化、质量门禁与描述性影响 |

## 2. 关键设计原则

1. **Motor-CAD 原生结果优先。** Studio 即时图用于设计理解；原生文件、消息、场点与网络表才可升级为原生证据。
2. **降级状态可见。** 无法解析绕组文本时保留 `NATIVE_RAW_ONLY`；没有热网络表时仅显示 `SUMMARY_ONLY`；点场不满足连续场重建条件时关闭网格边和等值线。
3. **对象边界不混淆。** Design、Scenario、Solver Profile 与 Case Result 分域保存，跨方案对比按域呈现变化。
4. **结论带适用范围。** 候选集参数—结果斜率标记为描述性关系，不解释为因果或全局灵敏度。

## 4. 数据与接口变化

### 4.1 绕组证据

- Case Artifact：`winding_pattern.txt`、`winding_definition.json`、`model_validation.json`。
- `winding_definition.json` 包含源文件 SHA-256、解析模式、线圈表、已验证原生字段、Design Revision 可编辑字段及原生消息结论。
- 工作台 `winding_design.definition_status`：
  - `STRUCTURED_NATIVE`：已从 Motor-CAD 文件解析实际槽对；
  - `NATIVE_RAW_ONLY`：保留原始文件但没有建立结构化声明；
  - `REVISION_PREVIEW_ONLY`：尚无真实 Case 证据。

### 4.2 热证据

- `GET /api/cases/{case_id}/thermal-network` 返回统一合同。
- `authority=motorcad_native_thermal_network` 时节点/边来自 Case 表。
- `authority=studio_engineering_summary` 时仅汇总已提取温度标量，不构造推测热阻连接。

### 4.3 FEA 证据

- `GET /api/cases/{case_id}/fea-evidence`：清单、字段、区域、帧、范围与能力。
- `GET /api/cases/{case_id}/fea-frames/{frame_index}`：当前求解步实际导出点。
- `GET /api/cases/{case_id}/fea-probe`：按 X/Y、字段和可选区域返回最近实际导出点。
- `GET /api/cases/{case_id}/fea-raw`：原始 CSV。
- 单元/节点编号只作为连接元数据保存；缺少节点坐标表时 `mesh_edges=false`、`filled_contours=false`。

### 4.4 决策对比

`GET /api/result-viewer/compare` 升级至 Schema 2，保留旧 `parameters/results/quality` 字段，同时新增：

- `traceability`：Design / Scenario / Run Configuration / Fingerprint；
- `changed_domains`：design / scenario / solver；
- `objectives` 与 `pareto`；
- `decision_summary`：改善、退化、质量门禁与警告；
- `influence`：候选集线性斜率，固定标注 `descriptive_only_not_causal`。

## 6. 真实工作站验收清单

V0.35 发布候选进入生产前需在 Windows + Motor-CAD 2026R1 完成：

1. 使用 i5、e9、e14 三类模板各导出至少一个绕组文件，核对解析槽对、相别、匝数和方向；未知格式必须稳定降级。
2. 对稳态热、瞬态热和电磁—热耦合 Case 核对原生热表字段与节点 ID，确认热阻/热流单位。
3. 用至少 3 个转子位置导出 B、Bx、By、Pt，核对 Step 顺序、区域代码、坐标单位、最近点探测和原始哈希。
4. 若要开放真实网格/等值线，必须先获得节点坐标表与完整单元连接，并与 Motor-CAD 截图做范围和热点位置结果验证。
5. 建立包含设计、工况、求解精度变化的 8 Case 对比，核对 Pareto 方向、质量门禁、单位和 Run Configuration 血缘。
6. 执行 20/100/500 Case 运行合同，记录许可证等待、Worker 复用、RSS 高水位、失败恢复和 Artifact 完整率。
