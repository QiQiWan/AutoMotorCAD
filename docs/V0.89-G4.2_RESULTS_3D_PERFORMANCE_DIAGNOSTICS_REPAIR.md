# V0.89-G4.2 结果、三维查看、性能与诊断修复

## 日志结论

用户诊断包记录了 4 次结果路由慢加载，耗时分别约 3.4、4.0、7.9 和 9.2 秒。计算本身已经完成，主要等待发生在结果页面：页面先串行读取项目结果工作台，再读取 ResultBundle；进入有限元模块后又默认拉取当前帧全部网格分块。29 帧数据因此出现长时间“读取完整网格清单”。

诊断包没有记录浏览器 `ReferenceError`，但源码确认项目概览直接调用了结果查看器闭包内部的 `experimentModeLabel`，两者不共享作用域，对应截图中的 `experimentModeLabel is not defined`。

## 已修复内容

- 项目任务摘要拥有独立的试验模式标签函数，消除未定义错误。
- 结果模块导航和详情面板以页面实际语言为权威，中文模式不再读取英文说明。
- 补充结果页和优化页常见英文动态文案的中文映射。
- 直接打开 ResultBundle 时，并行读取项目摘要与结果聚合，消除两段串行等待。
- FEA 首屏读取经过完整性登记的轻量原生场视图，不再默认下载全部网格分块；每帧切换同样保持轻量读取。
- 有限元查看器保留任意角度旋转、倾斜、平移和缩放，交互提示已明确；数据仍来自 Motor-CAD 原生场导出。
- 桌面端项目导航固定为三个等宽工程阶段，项目名称和诊断工具栏不再挤压主导航。
- 诊断报告新增最慢 HTTP 请求、请求状态、耗时、请求标识、前端事件时间线和慢请求计数。

## 性能边界

本轮优化首屏和逐帧浏览延迟。轻量场端点最多返回 20,000 个经过分区、极值和空间覆盖约束的显示单元，原始文件和完整网格证据继续保留。浏览器不再为普通查看自动下载每帧全部网格。
