# MotorCAD Studio V0.41：可读性、诊断与工作流修复

## 交付结论

V0.41 已完成本轮四类产品修复：全局比例与可读性、默认模型语义、诊断包根因、Motor-CAD 工作流衔接。实现完成度为 100%；目标 Windows 工作站上的真实 Motor-CAD 结果验证仍按运行合同单独记录。

## 诊断包结论

诊断包显示 Windows 10、Motor-CAD 2026R1、PyMotorCAD 0.8.6，Worker 能力状态为 READY。健康分数 48 的主要来源如下。

| 诊断证据 | 根因 | V0.41 处理 |
|---|---|---|
| `Cannot set properties of null (setting 'disabled')` | 异步事件结束后继续访问已经失效的 `event.currentTarget` | 在 `await` 前持有按钮引用，并在节点仍连接时恢复状态 |
| 已删除项目连续产生 project、simulation-assets、domain-integrity、ui-guidance 404 | 活动项目与路由中的旧 ID 没有统一失效处理 | 项目 404 时清空项目、设计与版本上下文，替换路由到项目管理，停止后续项目请求 |

## 全局排版修复

### 设计工作区

- 设计区在 1600 CSS px 以下从三栏切换为“模型树 + 主画布”，属性检查器下移，适配 Windows 125%/150% 缩放。
- Revision 从固定窄侧栏改成横向版本条，释放主画布宽度。
- 设计视图采用容器查询。画布宽度不足时，参数上下文自动移到图形下方，不再依赖浏览器视口宽度猜测。
- 径向、轴向、绕组和槽内 SVG 的可视高度提高到 500–660 px；有限元场视图提高到 540–760 px。
- 绕组图与参数摘要改成上下布局；相槽表、绕组指标、槽内定义和材料表字号提升到 11–13 px。
- FEA 图例、场元数据、热网络节点文字同步放大；有限元和热拓扑继续以原生证据优先。

### 计算设置

- 修复 `.wide` 字段没有跨越表单网格的基础样式缺陷。这是截图中按钮和说明被压成竖排的直接原因。
- “电机模型”改为“本次计算模型”，明确它决定本次计算的几何、绕组和材料基线。
- 项目与 Design Revision 保留在模型区；Solver Profile 移入“高级计算设置”。
- Design / Scenario / Solver / Output / Run Configuration 追溯默认折叠，需要时再展开。
- 任务主区在较窄桌面宽度下改为单列，计算摘要移到内容上方。

### 分析工作台

- 保留五模块、17 类分析配方入口。
- 创建分析定义取消浏览器原生 `prompt`，改用页内工程表单，可同时设置名称、首个运行点和原生画面证据。
- Analysis Definition 继续版本化，并可进入统一计算设置补充工况矩阵、求解参数和输出。

## 结果验证建议

1. 使用默认 BPM 模型进入设计页，在 100%、125%、150% 三种 Windows 显示缩放下检查七个设计视图。
2. 将槽数设为 18、槽口设为 8 mm，确认 Studio 在启动 Motor-CAD 前阻断并显示最大槽口建议。
3. 选择满足整数绕组关系的槽数并调整槽口，执行“Motor-CAD 检查并重绘”，确认原生几何与绕组均 PASS。
4. 分别创建电磁工作点、转矩包络、稳态热、耦合、Lab 与机械分析，确认分析定义及运行设置继承正确。
5. 完成真实 Case 后检查实时 FEA 场、原生画面、曲线、热拓扑、结果质量和诊断包证据。
