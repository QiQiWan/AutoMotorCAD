# MotorCAD Studio V0.9 Implementation

## Scope

V0.9 intentionally defers AI. The implementation focuses on adaptive engineering optimization and a simulation data factory that can later support surrogate models and multi-fidelity workflows.

## New backend modules

### `workspace.py`

Provides immutable engineering revision chains:

- Project
- Design
- DesignRevision
- Scenario
- ScenarioRevision

Every submitted Task also receives a persistent Experiment entity.

### `adaptive_optimization.py`

Implements archive-based NSGA-II style adaptive generation:

- constraint-aware scoring;
- Pareto rank;
- crowding distance;
- tournament selection;
- crossover;
- mutation;
- parameter bound clamping;
- deterministic seed;
- duplicate suppression.

Unlike V0.7 Pareto Search, later generations are created only after previous evaluated Case results exist.

### `derived_metrics.py`

Centralizes deterministic post-solver engineering features and constraint evaluation.

### `data_factory.py`

Implements automatic Task ingestion and immutable dataset versioning.

## Task finalization contract

A V0.9 Task does not transition to a terminal status until finalization has attempted:

1. optimization summary generation;
2. optimizer state update;
3. Data Factory ingestion;
4. final Task event.

This removes the race where clients observed `COMPLETED` before the data lineage became available.

## Adaptive NSGA-II execution

```text
Generation 0
  -> solve population
  -> quality + constraints
  -> archive scoring
  -> generate Generation 1
  -> solve
  -> archive scoring
  -> ...
```

The algorithm uses all evaluated archive rows as the parent candidate pool. This is appropriate for expensive simulation optimization because previously discovered elite designs remain selectable across generations.

The implementation is an engineering archive-based NSGA-II workflow, not a claim of bit-for-bit equivalence with every reference library implementation.

## Data Factory storage

Default:

```text
data/factory/
  raw_index/
  curated/
  features/
  datasets/
```

Override using:

```text
MOTORCAD_STUDIO_FACTORY_DIR
```

Tests use a separate temporary factory directory.

## Reliability corrections

### Simulation fingerprint

Materials, solver settings and automation overrides are now included. This closes a cache/data-lineage correctness gap in earlier versions.

### Task internal exception guard

Unhandled optimizer/orchestrator exceptions no longer leave a Task permanently `RUNNING`; the Task becomes `FAILED`, stores the traceback and emits `TASK_INTERNAL_ERROR`.

### Factory test isolation

Factory storage now has its own setting and tests do not write to delivery `data/factory`.

## Deferred intentionally

Not implemented as V0.9 completion criteria:

- AI assistant;
- surrogate training;
- Maxwell adapter;
- distributed cluster scheduler;
- full React/TypeScript engineering workspace;
- Lab Map2D canonicalization;
- production Motor-CAD SessionPool validation.

These depend on a stable real-data factory and are intentionally sequenced later.
