# V0.16 AFPM Runtime Notes

## e14 几何失败的判定顺序

1. **Baseline**：不修改参数，加载 e14 并做 Motor-CAD 几何检查。
2. **Slot count**：若只改槽数，Studio 同步 `Slot_Number`、`Stator_Poles`、`Stator_Pole_Angle`。
3. **Winding refresh**：槽/极/匝数等显式修改后刷新绕组。
4. **Geometry check**：先 `check_if_geometry_is_valid(0)`，失败后允许 `check_if_geometry_is_valid(1)` 尝试恢复，再复检。
5. **Explicit-value guard**：若恢复需要改变用户明确指定的设计变量，停止 Case，不静默修改设计。

## Slot Opening

真实日志中的核心错误为 Slot Opening 不满足当前机器约束，并伴随 `Stator` / `StatorAir` 相交。V0.16 将 `slot_opening` 作为强耦合参数；对于 e14 默认建议保持模板运行时值，除非已经完成目标版本几何校准。

## 材料错误

若日志出现 `set_component_material component=Stator Lamination ... failed`，首先检查：
- 用户是否真的主动选择了材料；V0.16 默认不覆盖模板材料；
- 目标 Motor-CAD 实际组件名；V0.16 会尝试背铁/齿等组件别名；
- 目标材料是否实际存在于当前 Motor-CAD 材料数据库；公共目录存在不代表 Motor-CAD 数据库存在。
