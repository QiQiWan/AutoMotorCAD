# V0.42 配方与能力证据合同

V0.42 将分析类型从展示用菜单升级为 Recipe Schema V3。17 个配方分别声明模块、原生方法、字段组、必需输出、可选输出和结果视图。前后端消费同一份 YAML 合同，新增字段不需要复制一套固定表单。

能力状态使用五级证据链：

1. `DECLARED`：注册了分析意图；
2. `CALLABLE`：所需方法进入内置官方 API 目录；
3. `CONFIGURABLE`：存在可渲染、可校验的专用字段；
4. `RESULT_VISIBLE`：必需输出已注册且存在工程结果视图；
5. `NATIVE_QUALIFIED`：目标模板、目标版本、目标配方已有 Level 4 真实求解 PASS 记录。

`production_ready` 仅在第五级为真，解决旧版本把“方法名称存在”当成原生资格的问题。
