# V0.15 Geometry and Observability Operations

## Geometry status meanings

**快速检查通过** means no obvious conflict was found from Studio canonical parameters. It is not a solver qualification.

**存在几何风险** means the relation deserves attention but should not automatically block the model, commonly because the suspicious value came only from a candidate template default.

**几何阻断** means a user-explicit design variable violates a safe engineering relation and the Case should not enter the solver.

**Motor-CAD几何检查通过** means the target model was actually loaded in an isolated Motor-CAD qualification process and its geometry check returned valid for the applied explicit design intent.

## Recommended e14 diagnosis

For the previously observed Slot Opening / StatorAir problem:

1. select e14;
2. keep design parameters unchanged;
3. run Studio fast geometry check;
4. run Motor-CAD geometry check;
5. if valid, modify only one geometry variable and repeat;
6. if invalid, inspect `model_validation.json`, `parameter_audit.json` and `runtime_defaults.json`;
7. do not bypass `GEOMETRY_INVALID` by blindly enabling Motor-CAD geometry repair.

## Log sessions

The Problems Center defaults to “仅本次启动”. Use this mode for normal operations. Disable it only when investigating a failure that spans a service restart or comparing an older release.

A diagnostic bundle remains the preferred support artifact because it contains raw/filtered central logs, Task state, Case logs, environment manifest and production calibration evidence.

## Candidate comparison

Inside Result Viewer -> Batch/Optimization:

1. select 2–8 rows;
2. click “对比所选”;
3. first selected Case is the baseline;
4. inspect result delta first, then changed parameters;
5. only promote a candidate after checking its quality status and any constraint violations.
