# V0.43 工程上下文工作台

项目内增加与 Motor-CAD 心智模型一致的九个上下文：Geometry、Winding、Input Data、Calculation、Temperatures、Output Data、Graphs、Sensitivity、Scripting。它们位于项目阶段导航下方，阶段负责工程对象流转，上下文负责当前对象的专业视角。

Input Data 分为 Cooling、Losses、Materials、Interfaces、Radiation、Convection、End Space、Flow Circuit。Flow Circuit 的语义固定为物理冷却流动网络，包含入口、泵、部件、出口、流量、压降和热交换；工程阶段流转统一称为工程工作流。

Winding 的信息架构包含 Pattern、Definition、Positions、Diagnostics。现有绕组排布、槽内导体定义和原生证据继续复用；尚未由 Motor-CAD 回读的导体位置保持未验证状态。
