# MotorCAD Studio V0.60.0 完成度与工程可用性审计

## 1. 版本目标

V0.60 把普通工程师的主流程固定为：

```text
项目 → 创建分析案例 → 设计电机 → 配置输入 → 计算前检查 → 设置工况并计算 → 结果验证
```

项目表示同一产品或研究目标。分析案例是日常工程操作单元，包含一台电机、一个分析类型、版本化物理输入、多次计算记录和结果。模板仅作为案例创建时的设计起点，不再充当项目或任务本身。

## 3. 分析案例流程

### 3.1 项目管理

- 创建项目只输入名称和说明。
- 项目卡展示分析案例数量、电机方案数量、正在计算数量和可用结果数量。
- 普通项目概览不再展示 Design/Scenario/Task/Run Configuration 等底层对象。

### 3.2 创建分析案例

- 选择案例名称和 17 类分析配方之一。
- 选择 BPM、IM、SRM、BPMOR、PMDC、SYNC、CLAW、IM1PH、SYNCREL 等 Motor-CAD 机型体系。
- 选择“机型默认模型”或该机型的工程模板。
- 选择尺寸、比例或自适应几何参数化方式。
- 后端在一个事务内创建电机、设计版本、分析定义和分析设置版本；任一步失败会回滚。
- 成功后直接进入电机设计，无额外“是否使用当前方案”步骤。

### 3.3 案例观察

案例观察页只显示当前工程决策需要的信息：分析类型、电机、状态、必需输入完成数、计算记录、可用结果，以及“设计电机、配置输入、计算前检查、设置并计算”四个动作。

## 4. 输入数据模块与求解映射

| 模块 | 主要输入 | 进入求解的方式 |
|---|---|---|
| 冷却 | 冷却方式、入口温度、体积流量、空气速度 | 物化到计算工况，热分析时写入已注册 Therm 参数。 |
| 损耗 | 损耗来源、铜阻温度修正、机械损耗、损耗表 | LossSource 映射到已注册 Therm 控制；完整模块保留在物理输入审计。 |
| 材料 | 定/转子、磁钢、导体、机壳、冷却介质 | 物化到 MaterialConfiguration，调用 Motor-CAD 组件材料与流体接口。 |
| 接触界面 | 接触热阻、间隙系数、轴承模型 | 作为版本化热边界进入任务快照和应用审计，供模板/专家映射消费。 |
| 辐射 | 启用、辐射温度、发射率 | 辐射温度物化到工况；完整边界进入任务快照和应用审计。 |
| 对流 | 对流关联、海拔、空气速度、换热系数 | 海拔与空气速度物化到工况；关联式及换热系数进入应用审计。 |
| 端部空间 | 端部关联式、通风口、旋转增强 | 进入版本化热边界与应用审计。 |
| 流动回路 | 流体、入口温度、流量、压降、方向 | 比普通冷却输入更具体，求解时优先物化入口温度/流量，并设置冷却流体。 |

后端 `prepare_request` 会从 `analysis_definition_revision_id` 自动读取最新输入模块。前端即使没有重复提交这些字段，任务也会获得同一版本；任务快照、指纹、多工况、质量检查和结果追溯看到的是同一份有效输入。

每个真实 Motor-CAD 工况生成 `physical_input_application.json`，记录输入模块、有效工况、材料映射及已写入的求解控制。该文件只出现在诊断包和高级下载中。

## 5. 计算前检查规则清单

| 类别 | 阻断规则 | 提示规则 |
|---|---|---|
| 输入完整性 | 当前分析必需的输入模块尚未逐项确认 | — |
| 几何 | 有效长度非正；轴径不小于转子；转子不在定子孔内；直径差不足以容纳双边气隙；磁钢超出径向空间；槽深穿透轭部；槽口超出槽距 | — |
| 绕组 | 相数/并联支路/匝数不是正整数；槽满率不在 0–1 | 槽满率高于 0.75；常规旋转电机使用奇数极 |
| 运行工况 | 转速或电流为负 | 带载工况母线电压非正 |
| 热边界 | 温度低于绝对零度；液冷无正流量；强迫风冷无正风速；发射率超出 0–1；流量或压降为负 | 冷却模块与流动回路流量不一致 |
| 材料 | 定子、转子、导体或机壳关键材料缺失 | 材料页冷却介质与流动回路流体不一致 |
| 求解设置 | 瞬态时间步非正或不小于总时长；机械网格尺寸非正 | 每电周期点数低于 12 |

规则执行三次：案例页即时检查、任务提交门禁、每个工况启动前检查。Studio 规则通过后，真实计算仍会在同一 Motor-CAD 会话中进行几何、绕组和模型检查。

## 6. 普通工程师界面清理

普通界面已移除或改写：

- Design 快照、Revision 哈希、原生证据等级；
- Task + 资源租约、Worker、Run Configuration、Session；
- JSON/MOT/manifest 文件清单；
- 重复的项目准备状态与底层对象汇总；
- 计算页重复的设计参数和材料覆盖面板；
- 同时存在于“输入数据”和“运行工况”的冷却/辐射/对流字段。

问题中心仍保留组件、阶段、进程号、关联计算和诊断载荷，原因是这些信息用于定位失败。默认列表展示工程化聚合结论，详细载荷保持折叠。

## 7. 监控与错误资料

任务日志覆盖输入组装、等待运行环境、启动求解器、加载模型、应用参数、应用物理输入、材料、模型检查、求解、有限元导出、结果提取、质量检查、归档和检查点。`CASE_INPUTS_READY` 记录输入模块与映射摘要；`PHYSICAL_INPUTS` 明确表示物理输入已经进入 Motor-CAD 适配器。

失败记录包含任务/工况关联、阶段、异常类型、错误消息、Motor-CAD 消息、参数/材料应用审计、结果提取清单、有限元清单和进程退出信息，诊断包可按任务导出。
