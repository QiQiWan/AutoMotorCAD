# V0.4 实施说明

## 目标

V0.4 集中解决 V0.3 审计中最影响工程可信度和批量效率的问题，不扩大电机拓扑或 Maxwell 功能范围。

## 已实施项目

### 1. 单位边界

新增 `motorcad_studio/units.py`，Canonical 参数不再假设与 Motor-CAD 自动化变量使用相同单位。

### 2. 配置 Schema

新增 `motorcad_studio/config_schema.py`，Registry 启动时完成 Pydantic 校验、conversion 校验和交叉引用检查。

### 3. 上下文参数写入

MotorCADAdapter 将 EMag 与 Therm 参数分阶段应用；运行时默认值和回读也按上下文执行。

### 4. 几何和绕组校验

关键绕组参数变化时尝试刷新绕组；求解前调用几何有效性检查，并保存 `pre_solve_model.mot`。

### 5. 模型策略

新增 development / validation / production。Validation 与 Production 禁止缺少本地 MOT 时回退注册模板。

### 6. Case 级并行

同一个 Task 的 Case 使用线程调度器并行提交到 SolverProcessRunner；真正求解仍在独立子进程中。

### 7. PID 安全

Cases 表增加 `worker_create_time`。恢复/终止前同时核对 PID 与进程创建时间。

### 8. 可选实例复用

Adapter 增加可选 `reuse_instances`；默认 false。启用时请求可复用实例，并在 Case 后释放为可复用状态。

### 9. 结果提取

EMag 结果在 EMag 完成后立即提取；Therm 结果在 Therm 完成后立即提取。新增 series extractor 框架。

### 10. 物理质量检查

新增机械功率一致性和效率一致性检查，以及 Series 长度/缺失检查。

### 11. API 性能

新增 Task summary 和 Cases 分页接口；GUI 的任务详情读取不再依赖完整 Task payload。

### 12. 测试隔离

`tests/conftest.py` 将 runtime/results/baselines 指向临时目录，避免交付数据污染和历史缓存干扰测试。

## V0.4 关键接口

```text
GET /api/tasks/{task_id}/summary
GET /api/tasks/{task_id}/cases?offset=0&limit=50
```

现有完整 Task、事件、取消、导出等 API 保持兼容。
