# V0.44 专用分析编辑器

分析创建与 Analysis Revision 编辑统一由配方合同驱动。电磁编辑器显示速度、电流、电压、相角和计算项；热编辑器显示边界、模型规模、损耗来源、耦合和瞬态控制；Lab 显示模型构建、工作点和 Duty Cycle；机械显示转速、参与部件、黏结和网格；实验设计显示模式与样本规模。

服务端在持久化前执行：默认值物化、必填校验、数值类型、整数、上下限、枚举取值和输出注册校验。`load_case`、`solver`、`automation.<Context>`、`experiment` 四类目标按稳定结构保存，任务载入时继续兼容旧 Revision。
