# V0.3 实施细节

## 参数解析

旧实现遍历全部分区并保留最后一个同名字段。新实现记录全部 occurrence，并按照 `Dimensions`、`Magnetics`、`Miscellaneous`、`Winding_Design` 等有效分区选择。以 e9 的 `Shaft_Speed` 为例，`Through_Vent=3000` 和 `Miscellaneous=6000` 同时存在，新实现选择运行工况对应的 `Miscellaneous=6000`。

## 真实模型加载

每套重点模板在 `model_sources.yaml` 中声明：

- 本地 MOT 路径；
- Motor-CAD 注册模板名称；
- 原始 MTT 路径。

运行时优先 `load_from_file(template.mot)`，缺失时回退 `load_template(name)` 并生成警告。

## 运行时审计

真实 Case 会保存：

- 模型来源；
- 运行时默认值；
- 参数候选变量、实际写入变量和回读值；
- 输出候选变量和实际命中变量；
- Motor-CAD消息；
- 软件版本。

## 进程隔离

父进程通过队列接收进度和结果。超时或强制取消时，使用 `psutil` 终止 Worker 及其后代进程。该机制已使用慢速 Mock 求解器完成超时和取消测试。

## 基准比较

基准 JSON 保存参数和标量结果。对比模块同时计算绝对误差和相对误差，并根据每项结果的容差生成通过/未通过结论及 HTML 报告。
