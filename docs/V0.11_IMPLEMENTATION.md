# MotorCAD Studio V0.11 Implementation

V0.11 的目标是把 V0.10 的工程工作区和可观测性能力进一步收敛为**非开发人员可操作的 Motor-CAD 工程前端**，同时建立结果查看器的核心数据合同。本版本暂不引入 AI。

## 1. 用户审计驱动的十二项改进

1. Project 增加 DELETE API 与 GUI 删除入口；默认 `preserve_history=true`，历史 Task/Case/Result/Dataset 不被物理删除。
2. 修复 MonitoringService 写结构化告警日志时错误使用 positional level 参数造成 `/api/system/metrics` 500 的问题；SSE 增加降级轮询。
3. RFPM/AFPM 快速示意图改为 Motor-CAD 风格工程配色，并由当前参数实时驱动。
4. `Engineering Parameter Inspector` 改为“工程参数编辑器”，增加用途说明、使用步骤、参数帮助、默认值/验证状态和技术映射折叠。
5. Expert Automation 参数按关键字和官方 description 提供中文用途说明；Solver Controls 也增加中文工程解释。
6. 新增 `config/material_catalog.yaml` 和 `/api/materials/catalog`，把常用公共牌号做成选择器，而不是要求用户填写材料映射文本。
7. Raw solver variables、Automation registry、API capability audit 迁入默认折叠的开发者区域。
8. 新增 `/static/help.html`，覆盖参数、自动任务、结果分析、数据工厂、日志与运行检查等复杂工作流。
9. 新增 Engineering Result Viewer，后端统一 Case 输入/结果/Artifact/Stage 数据，前端提供专业结果模块导航。
10. 增加中英文切换；Data Factory 动态内容改为中文优先并支持英文模式。
11. 在线诊断包扩展到滚动中央日志和 Task 下 Case 日志。
12. 深度运行检查独立子进程化并加入超时；修复许可证状态和安装选择提示的误导性。

## 2. 结果查看器数据合同

当前正式支持：

- `scalar`
- `series`
- `map2d / field`
- `spectrum`
- `artifact`

Motor-CAD Adapter 新增 registry-driven `magnetic_3d_graph` Map2D extractor。只有版本化 output mapping 明确给出 `graph_candidates` 时才提取，系统不会猜测不同模板的 Graph Viewer 名称。

## 3. Material Catalog 定位

内置材料表是**选型目录**，不是对供应商材料数据库的替代。公共记录可保存 Br、Hcj、BHmax、厚度、标准铁耗等摘要用于选择；正式计算仍调用 Motor-CAD `select_material_database` / `set_component_material` / `set_fluid`，并以目标数据库的完整曲线为准。

## 4. Preflight 新语义

浅检查：

- Python / OS；
- PyMotorCAD import；
- 目标映射版本；
- 安装发现和模型策略；
- 不启动 Motor-CAD。

深度检查：

- 在独立 `spawn` 子进程启动 Motor-CAD；
- 验证 RPC；
- 调用 licence/message API；
- 默认 60 秒超时；
- 超时终止检查进程树，主服务不阻塞。

`get_licence() is None` 现在属于 `INFO/unknown`，真实模块许可证仍以实际求解 checkout 是否成功为准。

## 5. 实时监控降级

System SSE：

- `retry: 3000`；
- 10 秒 comment heartbeat；
- 单次 `system_snapshot` 异常只发送 `system_error`，不主动关闭流；
- 浏览器连续 3 次 stream error 后切换 5 秒 HTTP polling；
- 点击 live badge 可以重新建立 SSE。

## 6. 尚需真实工作站验证

当前容器没有 Motor-CAD 软件与真实许可证，因此以下能力仍需 Windows 目标机验收：

- 真实 RFPM/AFPM 参数变化与 Motor-CAD 几何的一致性；
- 内置 catalog 的 `motorcad_name` 与目标材料数据库实际名称匹配；
- `get_magnetic_3d_graph` 在 i5/e9/e14 上的具体 Graph Viewer 名称与数据方向；
- Lab 图谱、机械/NVH 数据完整提取；
- 深度检查对不同许可证配置和不同 Motor-CAD 版本的行为。
