MotorCAD Studio 使用说明 / User Guide

面向非开发人员的快速指南。建议日常使用“工程模式”；只有需要已审核的Motor-CAD高级Automation参数时切换“专家模式”，维护原生变量/注册表时才使用“开发者模式”。

项目、回收站与版本

“删除项目”会移入回收站，不会解除Design/Revision/Task/Case/Dataset血缘；可从工程工作区的“回收站”恢复。永久清除仅面向开发维护，并会对历史Task进行额外保护。

工程参数编辑器

1. 选择模板
模板决定电机拓扑和默认参数。
2. 修改工程参数
气隙、外径、极槽数、磁体厚度、转速、电流等均在这里修改；右侧快速几何预览会实时变化。
3. 预检查
提交前检查范围、能力和场景。Motor-CAD真实几何合法性仍由求解前官方接口验证。

材料与高级设置

专家参数对应 Motor-CAD Automation Parameter Names。普通用户无需填写。只有标准工程参数未覆盖的高级功能才需要启用。

上下文：EMag=电磁，Therm=热分析，Lab=性能图谱/工作点，Mechanical=机械分析。

材料快速目录用于选型；精确 B-H、退磁和铁耗曲线以供应商和当前 Motor-CAD 材料数据库为准。

自动化任务怎么选

如果不知道算法名称，先点“任务模式向导”：选择“计算当前设计 / 研究一个参数 / 探索多个参数 / 寻找多目标折中”，系统会分别切换到Single / Sweep / Latin Hypercube / NSGA-II。

单次计算：第一次使用模板时优先选择，用于验证模型。
一维扫描：只研究一个参数，例如气隙。
Latin Hypercube：多个连续参数的高效设计空间采样，数据工厂常用。
Full Factorial：参数较少、每个参数离散水平有限时使用。
NSGA-II：明确了多个目标和工程约束后进行多代优化；不建议作为第一次运行模式。

结果查看器

结果查看器按 Motor-CAD 能力组织为总览、输入快照、电磁波形、谐波、FEA场结果、热结果、Lab图谱、机械/NVH和原生结果。灰色模块表示当前Case没有提取对应数据，并不代表Motor-CAD不支持。

Mock任务中的场图仅用于验证界面交互，会明确标记为“合成场”；工程判断必须使用真实Motor-CAD提取结果。

结果校准与 Graph 探测

PyMotorCAD 的 Graph 接口需要明确的 Graph Viewer 名称。先载入版本化推荐名称，再对照 Motor-CAD Help → Graph Viewer 修正名称；必要时勾选“探测前先执行一次真实计算”。探测成功后会保存为目标版本/模板的 VERIFIED 映射，并用于后续自动结果提取。

如果某项失败，优先检查：Graph名称、结果类型对应的 extractor、分析上下文、是否需要先执行计算以及 section number。系统不会假设一个 Graph 名称在所有模板和 Motor-CAD 版本中都相同。

结果查看器：批量与优化分析

参数—结果关系
选择一个设计参数作为X轴、一个结果作为Y轴，用于快速观察趋势和异常点。
Pareto前沿
用于多目标任务。绿色候选代表满足约束且当前非支配，红色表示违反工程约束。
平行坐标
同时比较多个设计变量与结果。适合筛选一组候选方案，不建议单独作为最终工程结论。

数据工厂怎么用

数据工厂把已经完成的仿真结果整理为可追溯数据集。普通用户通常只需要：选择来源任务 → 选择质量门禁 → 设置开发/验证/留出比例 → 构建不可变版本。

标准化数据统一参数、工况和结果字段；派生特征保存由原始结果计算的工程指标；隔离数据保存被质量门禁排除的样本及原因。

日志与问题中心怎么用

出现异常时先看“问题诊断”，重复错误会自动聚合。可按任务、Case、阶段或关键词筛选结构化日志。需要外部排查时点击“导出诊断包”，系统会打包中央日志、滚动日志、任务状态和Case日志。

运行环境检查与模板资格

浅检查不会启动Motor-CAD，只检查系统、PyMotorCAD、安装发现和平台配置。深度检查会实际启动Motor-CAD，检查RPC、许可证调用和消息接口，完成后关闭实例。

模板资格检查更进一步：加载指定模板，检查运行时参数、材料映射和几何；勾选“真实求解Smoke Test”后还会真正运行轻量EMag/稳态热计算。只有真实Smoke成功才应视为对应分析已具备工作站级资格。

手动绑定 Motor-CAD.exe

如果自动扫描不到安装路径，在“运行环境 → Motor-CAD 安装与启动路径”中可以粘贴完整EXE路径，或在本机Windows桌面会话中点击“浏览本机…”。绑定后 Studio 会把该路径设为当前运行时有效 Motor-CAD.exe，并通过 PyMotorCAD 的 set_motorcad_exe() 指定后续启动程序；安装变化会回收旧持久 Worker，避免继续使用旧路径。若服务器以Windows Service等非交互方式运行，原生文件窗口可能不可见，此时使用路径粘贴方式。

几何校验失败怎么处理

如果出现 Slot Opening 不可行、Stator 与 StatorAir 相交等信息，这属于几何约束问题，不是RPC故障。V0.15会在提交前先执行Studio快速几何筛查；需要时可点击“Motor-CAD几何检查”对当前显式修改参数做真实模型校验。正式求解仍保留Motor-CAD约束内恢复；若恢复需要改变你明确设置的参数，任务会以 GEOMETRY_INVALID 停止。请查看 Case 中的 model_validation.json、parameter_audit.json 和 runtime_defaults.json。

日志：本次启动与历史记录

日志页面默认勾选“仅本次启动”，用于避免历史版本已经修复的错误继续出现在当前问题中心。取消勾选即可查看全部历史日志。诊断包仍可导出中央日志、Case日志、资格证据和环境清单。

结果查看器：候选方案对比

在“批量/优化分析”的Case数据表中勾选2–8个Case，点击“对比所选”。第一项作为基准，系统并排显示关键结果、发生变化的设计参数以及相对基准的百分比变化。适合Pareto候选方案下钻比较。
